# GitHub 访问修复工具（国内网络）

一键解决「**GitHub 打不开 / 打开超时 / 时好时坏**」的小工具：自动探测 GitHub 官方 IP 池中当前可用的 IP，更新系统 hosts 中 `github.com` 的指向，并刷新 DNS 缓存。**全程无需科学上网，不改任何系统代理设置。**

| 使用方式 | 需要安装 Python？ | 适合人群 |
|---|---|---|
| ① 下载 Release 里的 `GitHubAccessFix.exe` | ❌ **完全不需要** | 怕麻烦、不想装环境的人 |
| ② 双击 `修复GitHub访问.bat` | ✅ 需要 Python 3.8+ | 想看/改源码的人 |
| ③ 命令行运行 `GitHub访问修复.py` | ✅ 需要 Python 3.8+ | 想传参、自动化的人 |

---

## ❓ 是否需要安装 Python？

**取决于你选哪种方式，大多数人选方式 ① 就行：**

### 方式 ①：免安装版（推荐，不需要 Python）

1. 打开本仓库的 [Releases 页面](../../releases)；
2. 下载附件 **`GitHubAccessFix-v1.0.0.exe`**；
3. **右键 → 以管理员身份运行**，完成。

> exe 是用 PyInstaller 把 `GitHub访问修复.py` 打包的独立程序，双击即用，不依赖任何已安装环境。
> 个别杀毒软件可能对打包 exe 误报，添加信任即可（源码就在本仓库，可自行审查或自己打包）。

### 方式 ②③：源码版（需要 Python 3.8+）

**第一步：安装 Python（已安装可跳过）**

1. 打开 https://www.python.org/downloads/ ，点击黄色的 **Download Python 3.x.x** 按钮；
2. 运行安装程序，**务必勾选底部的 `Add python.exe to PATH`**（最常见问题就是漏了这一步）；
3. 点 Install Now，等待完成。

**第二步：确认安装成功**

按 `Win + R` 输入 `cmd` 回车，在黑窗口里输入：

```bat
python --version
```

显示 `Python 3.x.x` 即安装成功（如果提示"不是内部或外部命令"，说明没勾 Add to PATH，重装并勾选，或改用 `py --version` 测试）。

**第三步：运行**

- **图形化（推荐）**：下载仓库里的 `修复GitHub访问.bat`，**右键 → 以管理员身份运行**。它会自动寻找你电脑上的 Python，找不到会给出安装指引；
- **命令行**：

```bat
:: 进入脚本所在目录后
python GitHub访问修复.py              :: 自动探测可用 IP
python GitHub访问修复.py 20.205.243.166   :: 指定 IP, 跳过探测
python GitHub访问修复.py --version        :: 查看版本
```

## 🚀 它做了什么

运行后会依次执行：

1. **探测**：对 GitHub 官方 IP 池逐个发起 HTTPS 探测（每个间隔 1 秒，避免触发频率阻断），找出当前可用的 IP；
2. **更新 hosts**：把 hosts 里 `github.com` / `gist.github.com` 的指向改为可用 IP（修改前自动备份到 `C:\Windows\System32\drivers\etc\hosts.bak-githubfix`）；
3. **刷新 DNS**：执行 `ipconfig /flushdns`；
4. 提示完成，直接刷新浏览器即可访问 GitHub。

内置 IP 池（GitHub 官方 IP，按近期可用性排序）：

```
20.205.243.166   20.27.177.113   140.82.113.3    140.82.116.3
140.82.112.3     20.26.156.215   20.200.245.247  140.82.114.3
```

## 🧠 为什么 GitHub 会打不开？

- 你的 hosts 里可能装过 **GitHub520** 等加速列表（https://raw.hellogithub.com/hosts ），它们把 `github.com` 钉在某个固定 IP 上；
- 这些 IP 会被网络环境**动态阻断**（今天能用的 IP 明天可能失效）；
- 于是出现「时好时坏 / 忽然打不开」。本工具就是把指向换到当前可用的 IP，**坏了随时再跑一次即可**。

## ❓ 常见问题

**Q1：运行 bat 提示"未检测到 Python"？**
见上文「是否需要安装 Python」——装 Python 时记得勾选 `Add python.exe to PATH`，或者直接用免安装的 exe 版。

**Q2：提示"请以管理员身份运行"？**
写 hosts 必须管理员权限：右键 bat / exe → **以管理员身份运行**。

**Q3：杀毒软件弹窗拦截？**
修改 hosts 属于敏感操作，部分安全软件会提示，点**允许/放行**即可。exe 版若被误报，加入信任或改用源码版。

**Q4：显示"✅ 完成"但个别页面还是异常？**
1. **完全关闭浏览器再重开**（浏览器有自己的 DNS 缓存）；
2. 仍不行就**重启一次电脑**（个别情况下系统的 DNS 缓存服务会卡在旧快照上，重启必定重载 hosts）。

**Q5：过几天又打不开了？**
正常现象——IP 阻断是动态的。**重新跑一遍本工具**换个 IP 即可；也可以顺手更新 GitHub520 的 hosts 列表。

**Q6：能一直探测/频繁运行吗？**
不建议。对 IP 池的高频探测可能触发更严格的阻断（工具已内置 1 秒探测间隔，正常每次运行只发 2~8 个探测请求，安全）。
